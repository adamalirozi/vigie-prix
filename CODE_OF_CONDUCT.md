# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/)
(texte intégral à l'adresse indiquée). En résumé : nous voulons une communauté respectueuse, ouverte à toutes et à tous,
quels que soient l'origine, le genre, l'âge, le handicap, la langue ou le niveau d'expérience. Les comportements
harcelants, discriminatoires ou hostiles ne sont pas acceptés.

Signalement : adam.ali@aims-cameroon.org. Les signalements sont traités avec confidentialité.
