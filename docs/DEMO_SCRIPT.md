# Déroulé de démonstration (7 minutes)

## Avant la réunion (10 minutes avant)
- [ ] Ouvrir l'application (la réveiller si elle dort) ; vérifier le bandeau « Démonstration ».
- [ ] Parcourir une fois chaque vue et charger les 3 épisodes : la première visite d'une date de relecture prend quelques secondes.
- [ ] Salle sans internet fiable : activer « Carte sans fond (hors ligne) ».
- [ ] Avoir le brouillon Word téléchargé à l'avance (secours).

## Déroulé
1. **Le constat (1 min)** — vue *Provinces*, bouton M+1/M+2/M+3. « Le SISAAP décrit très bien ce qui se passe ; nous ajoutons ce qui va probablement se passer. »
2. **Agir avant la hausse (2 min)** — Épisode d'illustration → « Soudure 2024 · mil, Hadjer-Lamis ». Montrer la courbe verte (réalisé) :
   « L'alerte part un mois avant ; la hausse a été plus forte que la projection. C'est la limite de la méthode simple. »
3. **Validation (1 min)** — profil *Analyste SISAAP* → *Alertes* → valider, commenter ; lire le message au Cluster : « Rien ne part sans validation. »
4. **MEB (1 min)** — coût de la ration céréalière, seuil réglable : « Seuil et composition à fixer avec vous. »
5. **Al Aswak (1 min)** — brouillon généré, export Word : « Les analystes gardent la décision finale. »
6. **Honnêteté (1 min)** — *Fiabilité & données* : « Voici ce que la méthode simple sait faire et ne sait pas faire ; les niveaux 2 et 3 doivent la battre. »

## Questions probables
- *Pourquoi les données s'arrêtent à juin 2026 ?* Données publiques WFP ; l'audit les remplace par les séries SIMPA.
- *Les seuils sont-ils officiels ?* Non, « non validés par le SISAAP » : ils se fixent ensemble.
- *Et le carburant, la pluie, le conflit ?* Niveau 2, non connecté dans la démonstration.
- *Qui voit nos données ?* Aucune donnée de ménage ; ici, uniquement des données publiques.
